Format Reference

          

            Supported formats: JSON, CSV, TSV


            Generic data (any columns) — each row becomes an INS event:

            
name,email,status
Alice,alice@example.com,active
Bob,bob@example.com,pending

            Event format (with op + target columns) — imported as-is:

            
op,target,operand
INS,app.tbl.rec1,"{""name"":""Alice""}"

            JSON examples:

            
[{"name":"Alice","email":"alice@example.com"}]
[{"op":"INS","target":"app.tbl.rec1","operand":{"name":"Alice"}}]

            Valid operators: INS, DEF, CON, SEG, SYN, EVA
